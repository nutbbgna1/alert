# Alert Green Demo

A responsive static demo for an Alert / reminder web app.

## Features
- Responsive desktop, tablet and mobile UI
- Green minimal design
- Dashboard / Today / Calendar / All Alerts / Notes / Categories / Settings
- Create alerts
- Mark alerts as completed
- Delete alerts
- Add and delete notes
- Search and filter alerts
- LocalStorage persistence
- Demo Google Calendar connection state
- Browser notification permission toggle

## Run

### Option 1
Open `index.html` directly in a browser.

### Option 2
Run a local server:

```bash
python3 -m http.server 8080
```

Then open:

http://localhost:8080

## Important
Google Calendar and Email are simulated in this demo.
A production build should use server-side OAuth, a database, and an email provider.
